# Rencana uji penggunaan

Status: belum dilaksanakan. Hasil pengujian otomatis tersedia terpisah di [laporan validasi](../reports/validation_summary.md).

Tujuannya memeriksa apakah pembaca memahami perubahan harga, asumsi keranjang, dan hasil yang belum lengkap. Rencana awal melibatkan 3–5 peserta, termasuk pembaca yang belum pernah melihat dashboard.

| Tugas | Hal yang diamati |
| --- | --- |
| Jelaskan temuan utama setelah melihat Ringkasan selama satu menit | Ketepatan membaca periode, jumlah pembanding, dan kenaikan harga |
| Bandingkan keranjang Latihan A dan B | Pemahaman bahwa dampak biaya bergantung jumlah belanja |
| Ubah satu jumlah dan harga pada simulator | Kemudahan mengedit dan memahami perubahan hasil |
| Pilih Januari 2021 | Pemahaman bahwa subtotal bukan total lengkap |
| Unduh skenario | Kesesuaian isi file dengan input yang digunakan |

Catatan sesi menggunakan kode peserta anonim, tugas, waktu, kesulitan, dan kebutuhan bantuan. Partisipasi bersifat sukarela. Hasilnya digunakan untuk perbaikan antarmuka; tidak mengukur dampak finansial usaha.
