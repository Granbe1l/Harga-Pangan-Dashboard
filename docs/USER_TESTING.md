# Rencana uji penggunaan

Status: belum dilaksanakan. Pengujian otomatis tersedia di [laporan validasi](../reports/validation_summary.md).

Rencana awal melibatkan 3–5 peserta untuk memeriksa apakah tujuan dashboard dan temuan harga dipahami tanpa penjelasan tambahan.

| Tugas | Hal yang diamati |
| --- | --- |
| Jelaskan temuan Ringkasan dalam satu menit | Ketepatan membaca periode, kenaikan, dan jumlah pembanding |
| Ubah komoditas dan rentang pada Tren & fluktuasi | Pemahaman perbedaan tren harga dan perbandingan fluktuasi |
| Pilih Januari 2021 | Pemahaman bahwa perubahan belum dapat dihitung tanpa pembanding |
| Bandingkan satu bahan antarwilayah | Pemahaman median tanpa bobot dan keterbatasan perbandingan |
| Unduh laporan Excel | Kesesuaian laporan dengan filter yang dipakai |

Catatan sesi menggunakan kode anonim, tugas, waktu, kesulitan, dan kebutuhan bantuan. Partisipasi bersifat sukarela. Hasil digunakan untuk perbaikan antarmuka.
