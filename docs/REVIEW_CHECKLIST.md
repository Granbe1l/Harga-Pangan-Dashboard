# Checklist penerimaan portofolio

Daftar ini mengukur bukti yang dapat diperiksa, **bukan skor resmi HRD atau jaminan nilai 8/10**. Nilai rekrutmen bergantung rubrik dan penilai.

| Pemeriksaan | Bukti yang perlu tersedia |
| --- | --- |
| Masalah dan hasil cepat dipahami | Halaman depan menampilkan temuan harga; studi kasus satu halaman |
| Sumber aktif dapat ditelusuri | Ekspor CSV/XLSX unggahan, URL publikasi, nama asli, hash, receipt, dan konfigurasi input |
| Dua format diperiksa | Tes seluruh baris CSV–XLSX serta hash asli; tidak mengaku server diverifikasi langsung |
| Pembersihan dan matematika dapat diulang | Karantina dengan baris asli; pemeriksaan Decimal independen untuk temuan bulanan |
| Asumsi dipisahkan dari hasil | Tab Temuan harga tidak memakai kuantitas; tab keranjang menyatakan asumsi |
| Analisis dan ekspor konsisten | Kalender tepat, bulan bersama, subtotal, batas anggaran, sumber harga/satuan |
| Tes dan CI tersedia | Unittest, browser acceptance, workflow push/pull request, dan bukti hasil aktual |
| Paket dan tampilan dapat digunakan | ZIP hasil ekstraksi, unduhan laporan, desktop dan ponsel diperiksa |
| Akses aplikasi publik | Perlu URL hosting untuk pengujian incognito dan sleep; belum dibuktikan |
| Pemahaman pengguna nyata | Protokol tersedia; hasil peserta manusia dan dampak usaha belum dibuktikan |

Delapan pemeriksaan teknis pertama harus didukung hasil rilis aktual. Dua pemeriksaan terakhir memerlukan bukti di luar pemeriksaan kode. Satuan sumber/lisensi yang tidak tersedia tetap dicatat, bukan dianggap selesai karena format data berubah.
